# lintlink

Lint encode/decode helpers for link payloads in pipelines.

**Site:** https://theworker02.github.io/lintlink/

## Install / run

```bash
git clone https://github.com/theworker02/lintlink.git
cd lintlink
node src/cli.js
node --test
```
